# HOMETS app icon

Created with the built-in image generation tool. The original generated image is exported at 1024px; the smaller PNGs are resized exports of the same design. All exports have an opaque square background. The OS applies its own home-screen mask.

- `homets-icon-1024.png`: master export
- `icon-192.png`, `icon-512.png`: Android / web app icons
- `icon-maskable-512.png`: Android adaptive mask
- `apple-touch-icon.png`: iOS Add to Home Screen, 180px
- `favicon-32.png`: browser tab icon

## Generation prompt

Use case: logo-brand. Create one final production app icon for HOMETS, a compact English gym workout logging app whose visual identity is electric blue #2368F5 with deep navy #142542. Asset: square mobile home-screen icon, flat edge-to-edge square opaque background, 1024 by 1024 composition. A single bold clean white dumbbell emblem with subtly H-shaped negative space, centered, geometrically balanced, recognizable even at 32px. Cobalt blue background with a restrained slightly lighter blue upper-left to darker lower-right gradient. Thick precise vector-like forms, very high contrast, premium fitness app feel. Emblem occupies central 55% of canvas so it survives circular and rounded-square masking. No letters or text, no mockup, no phone, no border, no pre-rounded outer corners, no external shadow, no scenery, no extra symbols. Output exactly one icon.
